# .claude Directory

This directory contains Claude-specific documentation and configuration for the NautilusTrader codebase.

## Files

- **claude_docs.md** - Main documentation about the codebase architecture, entry points, and usage patterns for Claude AI assistant
- **README.md** - This file explaining the .claude directory structure

## Purpose

The `.claude` directory provides structured information to help Claude understand:
- The codebase architecture and component organization
- Key entry points and how to use the system
- Development workflows and testing patterns
- Build system and configuration options

This documentation is specifically formatted to help Claude provide better assistance when working with the NautilusTrader codebase.
